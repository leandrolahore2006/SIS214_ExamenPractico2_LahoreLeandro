01 / SOBRE MÍ

Un poco sobre mi perfil

Soy estudiante de la Universidad Católica Boliviana “San Pablo” y bachiller del Colegio Domingo Savio. Actualmente estoy ampliando mis conocimientos de tecnologías web mediante las actividades de la materia y la práctica aplicada en proyectos académicos.

Me interesa entender cómo cada parte de un sitio contribuye a la experiencia de quien lo utiliza: desde una estructura semántica bien organizada hasta un diseño que se adapte a diferentes pantallas y controles que respondan de forma clara.

En este portafolio reúno mi formación y trabajos, incluido el modelado de un sistema hospitalario y la implementación de este mismo sitio. Mi objetivo es seguir aprendiendo, cuidar los detalles y convertir cada ejercicio en una oportunidad para mejorar.

Mi forma de trabajar

Aprendo construyendo. Primero organizo el contenido y defino qué debe poder hacer una persona; después desarrollo la interfaz y reviso cómo se comporta en distintos tamaños de pantalla.

También procuro comprobar las interacciones y corregir los detalles que dificultan el uso, como mensajes de validación poco claros o elementos que no se adaptan bien al móvil.

  • Aprendizaje continuo y práctica aplicada
  • Atención a la estructura y presentación
  • Interés en accesibilidad y diseño adaptable

Aprender construyendo

01

Desarrollo de este portafolio

Proyecto académico · Tecnologías Web I

Diseñé y construí este CV web con HTML semántico, CSS adaptable y JavaScript. Organicé el contenido en secciones para presentar mi perfil, estudios, habilidades, proyectos y material multimedia.

El sitio incorpora navegación móvil, cambio entre temas claro y oscuro, búsqueda de proyectos, consulta de repositorios públicos y validación de campos con mensajes accesibles. También preparé recursos de imagen, audio y video para acompañar el contenido.

02

Modelado de un sistema hospitalario

Práctica académica · Modelo entidad-relación

Representé las entidades principales de un sistema hospitalario, entre ellas persona, paciente, médico, especialidad, consultorio y cita médica, y mostré cómo se relacionan entre sí.

El diagrama permite observar la organización de los datos de pacientes y profesionales, así como la información necesaria para registrar y gestionar citas. Incluí una imagen y una presentación del proyecto en la sección multimedia.
